# relcc2

A free (GPL) GCC backend for the Elbrus (E2K) architecture.

The work starts with a written, backend-neutral specification of the ISA and
ABI, with machine-readable data and tools that check it against the
reference toolchains. The GCC port is built on top of it. MCST already
publishes GPL ports of binutils, glibc, gdb, Linux and the GCC runtime
libraries for E2K; the compiler itself is the missing piece.

## Layout

- `spec/`: facts about the architecture, each with its source. The YAML files
  are machine-readable and generated by `tools/`.
- `tools/`: extractors and cross-checkers that build `spec/` from public
  sources.

## Sources

Spec data comes only from openly licensed material:

- MCST binutils, glibc and Linux sources (GPL/LGPL), via the OpenE2K git
  mirrors.
- MCST's programming guide "Руководство по эффективному программированию на
  платформе «Эльбрус»" (CC BY 4.0).
- The community and MCST QEMU e2k targets (GPL).

Proprietary compilers are used only as black-box oracles: we compare their
output and observe their behaviour. Their code is never copied into this
repository.

The reference sources are git submodules (`git submodule update --init`):

```
OpenE2K/binutils-gdb          MCST binutils 2.41    github.com/OpenE2K/binutils-gdb
OpenE2K/gdb                   MCST gdb 15.2         same repository, gdb-15.2-mcst branch
OpenE2K/glibc                 MCST glibc 2.35       github.com/OpenE2K/glibc
OpenE2K/linux                 MCST Linux 6.1        github.com/OpenE2K/linux
OpenE2K/qemu-e2k-community    community QEMU e2k    github.com/OpenE2K/qemu-e2k
OpenE2K/qemu-e2k-mcst         MCST QEMU e2k         git.openelbrus.ru/mcst/qemu
```

## Toolchains

The scripts in `tools/setup/` install the reference toolchains into
`toolchains/` (untracked). The tools in this repository look for them there.

| Script | Installs |
|---|---|
| `setup-unipro.sh [DEB_DIR]` | Unipro's LLVM 20 with the Elbrus target, from the x86_64 debs in `x86_64/`, as `toolchains/unipro/bin/{clang,llc,…}` |
| `build-binutils.sh` | MCST binutils built from `OpenE2K/binutils-gdb`, in `toolchains/binutils/bin/e2k-linux-*` |
| `fetch-lcc.sh [VERSION] [TARGET]` | MCST lcc cross compiler (default 1.29.16, `e2k-v5`) from the archive at https://setwd.ws/sp, as `toolchains/lcc-VERSION-TARGET/{lcc,l++,ldis}`. It needs `bwrap` |

lcc includes a sysroot, so it can link complete programs for E2K.
